# Narenthiran's Portfolio Template ^_-

**Welcome to your new portfolio!** 🚀

This is a research-oriented, high-performance personal portfolio template designed for roboticists, engineers, and creative developers. It features a premium "Deep Space Nebula" aesthetic, interactive elements, and a clean, modular structure.

> **Note**: This repository is the actual source code for my personal website. Feel free to use it as a starting point for your own!




## 🏁 Getting Started

Using this template is super easy. I've documented *everything* you need to know in the **[Maintenance Guide](MAINTENANCE_GUIDE.md)**.

### 1. 🍴 Fork & Clone
Star this repo (⭐️) and fork it to your own GitHub account. Clone it effectively to your local machine.

### 2. 📖 Read the Guide
Open **[`MAINTENANCE_GUIDE.md`](MAINTENANCE_GUIDE.md)**. This is your bible. It explains:
*   How to update your **Personal Details** (Name, Bio, Social Links).
*   How to add **New Projects, Research & Achievements** (using the included templates!).
*   How to configure the **Contact Form** (powered by Google Forms, no API keys needed!).
*   How to customize the **Mascot** and **Visual Effects**.

### 3. 🎨 Make it Yours
*   **Update `index.html`**: Replace my name, bio, and links with yours.
*   **Replace Assets**: Swap out the images in `assets/` with your own cool photos and GIFs.
*   **Customize**: Tweak the colors in `css/styles.css` if you want a different vibe (but the cyan/dark mode is pretty sleek, just saying ^_-).
