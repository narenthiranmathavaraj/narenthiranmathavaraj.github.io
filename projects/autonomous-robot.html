📝 Executive Summary

This project focuses on autonomous navigation in unstructured agricultural environments, where robots must distinguish traversable vegetation, non-lethal obstacles (e.g., tall grass and branches), and lethal obstacles (e.g., humans and trees), while adapting to varying terrain traversability. I am developing a Nav2-based ROS stack for a UGV that fuses LiDAR and RGB-D data to generate adaptive semantic costmaps beyond traditional heightmaps for autonomous field navigation.

Right Now, I developed a follow-me feature capable of robust person tracking under multiple people and partial occlusions, along with a control algorithm to reduce slip and stall during turning, improving reliability on low-traction terrain.

0 Number of Human Interventions

🎯 Key Features

  • Follow-Me Mode: Robust person tracking even with occlusions (using Yolo11 and YoloE).
  • Unmaned Ground Vehicle: RigBetel Labs' Diadem.
  • Sensor Fusion: Velodyne LiDAR + Realsense RGB-D Camera.
  • RL Navigation: Custom PPO agent for terrain analysis.
  • Mapless: Operates without prior 2d occupancy grid static map.

🚩 Challenges

Implementing a real-time, human-tracking and segmentation algorithm that ensures accurate, identity-consistent tracking of a designated person without mis-segmenting other individuals even under partial occlusions, enabling fast and safe decision-making within the Nav2 navigation framework. Researching optimal approaches to implement adaptive costmaps for agricultural fields using reinforcement learning, with a focus on safe operation in environments shared with humans.
