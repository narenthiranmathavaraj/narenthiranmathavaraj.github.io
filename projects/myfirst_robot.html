Line Follower - Test Run

📝 Executive Summary

This project involves the design and development of a simple line-following robot capable of autonomously following a black line. The robot’s infrared (IR) sensors were calibrated by hardcoding intensity values to reliably differentiate between black and other colors, enabling accurate line tracking. This project demonstrates fundamental concepts in sensor-based autonomous navigation and embedded system control.

1st Project

🎯 Key Features

  • Hardware: Electrical mica board chassis, 9V batteries, Arduino Uno, H-Bridge shield, DC motors, and IR sensors.
  • Control Logic: Basic Arduino loops to turn left or right based on IR sensor detection of the track.
  • Autonomous Navigation: Enables the robot to follow a black line using sensor-based feedback.

🚩 Results

The robot successfully followed a black line using the calibrated IR sensors.

The sheer joy of Building and Watching the robot come to life, this Tiny Project born out of boredom during the COVID-19 Pandemic, made me realize my passion for Electronics and Robotics.
