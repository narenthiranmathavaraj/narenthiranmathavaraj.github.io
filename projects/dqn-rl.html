DQN Agent Balancing Pole [Results]

📝 Executive Summary

This project applies Deep Q-Learning to the CartPole-v0 environment, progressing from a baseline DQN to an improved DDQN with Prioritized Experience Replay (PER). The initial DQN successfully balanced the pole but suffered from lateral drift due to the default reward function. By reshaping the reward to penalize cart displacement, the agent achieved stable, centered control.

Further improvements using DDQN reduced Q-value overestimation, while PER increased sample efficiency and accelerated convergence. Comparative results show faster learning, improved stability, and more robust performance compared to vanilla DQN.

4 Neural Layers

🎯 Key Features

  • Epsilon-Greedy Policy: Balances exploration and exploitation.
  • Experience Replay: Decorrelates training samples for stability.
  • Target Networks: Soft updates to prevent oscillation.
  • Convergence Analysis: Verified via reward plots in Jupyter.
