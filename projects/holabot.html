Hola Bot (Holonomic Robot)

ROS1 OpenCV Fusion 360
▶

Hola Bot in Action - Drawing Artworks

📝 Executive Summary

Hola Bot is a 3-wheel omnidirectional robot design to execute complex planar trajectories (3-DOF). The robot uses visual feedback to "draw" artwork on the canvas.

It combines ArUco marker localization with PD control loops to correct path errors in real-time, bridging the gap between high-level path planning and low-level motor actuation.

3 Degrees of Freedom Holonomic Drive

🎯 Key Features

  • Holonomic Motion: Instant movement in any x, y, theta direction.
  • Visual Servoing: Real-time pose estimation via overhead camera (ArUco).
  • PD Control: Tuned control loops for precise curve tracing.
  • WiFi Bridge: Custom communication between ROS Desktop & eYFi-Mega ESP32.

🚩 Results

Successfully fabricated the Hola Bot, which autonomously drew multiple vector art designs. Semi-Finalist in the Eyantra Robotics Competition, conducted by Indian Institute of Technology Bombay (IIT - Bombay).
